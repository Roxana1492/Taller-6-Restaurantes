# Taller 6 - Restaurantes (Swing)

## Contenido
- `src/`: código del proyecto.
- `imagenes/`: mapa y estrellas que usa la interfaz.
- `DiagramaClases.png`: diagrama de clases de la aplicación.

## Cómo ejecutar
1. En Eclipse: `File > Import > General > Existing Projects into Workspace` y seleccionar esta carpeta.
2. Abrir `src/uniandes/dpoo/swing/interfaz/principal/VentanaPrincipal.java`.
3. Clic derecho > `Run As > Java Application`.

Las imágenes se cargan con rutas relativas (`./imagenes/...`), por eso la aplicación se debe ejecutar desde la carpeta del proyecto (Eclipse lo hace así por defecto).

## Uso
- **Nuevo**: abre la ventana para crear un restaurante. Se hace clic en el mapa para marcar la ubicación, se llenan los datos y se oprime **Crear restaurante**.
- **Ver todos**: abre el mapa con los restaurantes. Con **Todos** / **Visitados** se elige cuáles se muestran.
